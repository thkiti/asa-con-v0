# Bundled fonts for server-side PDF generation

`NotoSansThai-Regular.ttf` is required for Manual Journal Entry PDF rendering (PDFKit).
Source: [googlefonts/noto-fonts](https://github.com/googlefonts/noto-fonts) — `hinted/ttf/NotoSansThai/NotoSansThai-Regular.ttf` (OFL-1.1).

Do not remove; Vercel and local PDF generation read this file from `public/fonts/` at runtime.
