# components/ui

Shared ASA-CON UI primitives.

| Component | Role |
|-----------|------|
| `PeriodSelector` | Calendar Year/Month → `periodKey` |
| `ModalShell` | Shared dialog overlay / panel chrome |
| `ConfirmDialog` | Simple confirm / cancel dialogs |
| `StatusBadge` | Visual status chip (domain maps status → tone) |
| `TrafficLightStatusDot` | Red / yellow / green status indicator |
| `PageBackDotButton` | Red circular back navigation |

See `docs/ASA_CON_UI_STATUS_NAVIGATION_STANDARD.md`.
